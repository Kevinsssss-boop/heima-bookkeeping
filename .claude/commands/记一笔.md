# 记一笔

帮助用户快速添加一笔支出记录到 K记 App。

---

## 对话流程

当用户调用这个命令时，按以下步骤与用户对话，**每次只问一个问题**，不要一口气问完。

### 第 1 步：询问金额

- 问用户："花了多少钱？（单位：元）"
- 如果用户输入的不是数字，友好地提示重新输入
- 金额保留两位小数，例如 `20.00`、`35.50`

### 第 2 步：选择一级分类

向用户展示所有一级分类，让用户选择：

```
🍜 餐饮    🚗 交通    🛒 购物    🏠 住房    🎮 娱乐    💊 医疗
📚 教育    📱 通讯    👥 人情往来    💰 金融理财    📦 其他
```

> 用户可能还有自定义分类，读取 `custom-categories.json` 获取完整列表。

### 第 3 步：选择二级分类

用户选完一级分类后，展示该分类下的所有二级小类（含图标），让用户选择。

**完整分类体系：**

| 一级 | 二级小类 |
|------|---------|
| 🍜 餐饮 | 🌅早餐、☀️午餐、🌙晚餐、🍿零食小吃、☕饮品咖啡、🍻朋友聚餐 |
| 🚗 交通 | 🚌公交/地铁、🚕出租车/网约车、⛽加油充电、🅿️停车费、🚄火车/高铁、✈️飞机机票 |
| 🛒 购物 | 🧴日用百货、👔服装鞋帽、📱数码产品、🛋️家居用品、💄个护美妆 |
| 🏠 住房 | 🏠房租、💧水费、⚡电费、🔥燃气费、🏢物业费、🔧维修保养 |
| 🎮 娱乐 | 🎬电影演出、🎮游戏充值、🎵音乐/视频会员、🧳旅游出行、🏋️运动健身 |
| 💊 医疗 | 🏥门诊挂号、💊药品购买、🛌住院治疗、🩺体检检查 |
| 📚 教育 | 📚课程/培训、📖书籍购买、✏️文具用品、📝考试报名 |
| 📱 通讯 | 📞手机话费、📶宽带网费、📦快递邮寄 |
| 👥 人情往来 | 🧧红包/礼金、🍽️请客吃饭、🎁节日礼物 |
| 💰 金融理财 | 🛡️保险支出、📉投资亏损、🏦银行手续费 |
| 📦 其他 | 📌其他支出 |

> 如果用户说的分类不存在，提示用户可以先在 App 的"分类管理"中添加自定义分类。

### 第 4 步：选择日期

- 问用户："是哪天花的？"
- 如果用户说"今天"，自动使用当前日期（格式 YYYY-MM-DD）
- 日期不能是未来日期

### 第 5 步：填写备注（可选）

- 问用户："有什么备注要写吗？（可跳过，最多 200 字）"
- 用户说"没有"、"不用"、"跳过" 就跳过
- 备注不超过 200 字

### 第 6 步：确认并保存

把收集到的信息汇总展示给用户确认：

```
📋 请确认这笔支出：

  金额：¥35.50
  分类：🍜 餐饮 → ☀️ 午餐
  日期：2026-07-29
  备注：和同事一起吃的

确认保存吗？（回复"确认"或"好的"保存，回复"取消"放弃）
```

## 保存数据

用户确认后，使用 Node.js 或 PowerShell 脚本直接写入数据文件。

**数据文件路径**：`C:\Users\kevin\AppData\Roaming\heima-jizhang\expenses.json`

**记录格式**：
```json
{
  "id": "<UUID>",
  "amount": 35.50,
  "category1": "餐饮",
  "category2": "午餐",
  "date": "2026-07-29",
  "note": "和同事一起吃的",
  "createdAt": "<ISO 时间戳>"
}
```

**保存方式**：
1. 读取 `expenses.json` 文件
2. 向数组末尾追加新记录
3. 写回文件

> ⚠️ 如果 App 正在运行，保存后提醒用户刷新页面（按 F5）即可看到新记录。

---

## 注意事项

1. **金额必须大于 0**，不能是负数或零
2. **分类**必须从现有分类中选择，不能随意编造
3. **日期**不能是未来日期
4. 如果用户中途说"算了"、"取消"，就停止流程
5. 每次只问一个问题，让对话自然流畅
